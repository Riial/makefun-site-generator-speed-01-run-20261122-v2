# site-generator-speed v2

Faster static-site generator for make.fun — pure JavaScript, no native code.

`solve.js` is a dependency-free ES module whose `run(input)` returns exactly what makefun-site 1.0.0 returns, byte for byte — faster than v1 (~15% less CPU). `main.ts` is the house driver. See `BUILD-SUMMARY.md` for the numbers.
